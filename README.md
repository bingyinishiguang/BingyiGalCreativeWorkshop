冰翼Gal创作工坊

一个仍在开发中的本地Galgame素材与创作工具，功能和界面可能调整。

源码运行需要Windows、Python3.11以上：

```powershell
py -3 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.\启动冰翼Gal创作工坊.bat
```

游戏素材、音色和模型需自行准备，本仓库不提供。
