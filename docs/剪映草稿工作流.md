# 剪映草稿工作流

导入剧情、安排画面和声音，再生成剪映草稿，在剪映中完成精剪和成片导出。「预览 MP4」用于检查演出。

## 输出目录

在「角色与声音 → 草稿与素材目录」中选择草稿目录和素材保存目录。粗剪工作区的「项目与导出设置」提供同样的设置，栏目生成与对白铺轨沿用粗剪输出配置。留空时使用工坊默认目录。

素材使用可读文件名，重名时增加版本号，已有文件不会被覆盖。剪映引用绝对路径，移动素材后需要重新关联。

每次生成独立草稿。建议在剪映复制生成稿后继续精剪。生成目录中的 `bingyi-story.json` 保存剧本和演出参数，`bingyi-generation.json` 保存片段 ID、时间和素材目录。

## 草稿内容

背景、人物、对话框、头像、人物名、对白、配音和 BGM 分轨保存。文字保持可编辑，人物位置和缩放可继续调整。旁白沿用项目或单句设置的时长。

四种对话框皮肤使用相同底板与文字布局，区别为配色。底板透明度可调整，姓名牌可在暂停时双击编辑。角色姓名修改会同步关联台词，可撤销。

底部 SAVE、LOAD 等菜单作为视频中的视觉图层，不提供游戏存档功能。预览和草稿使用相同的菜单、语音进度条与继续提示素材。图形源文件位于 `tools/story-kit-source`。

## 在剪映中检查

生成后打开草稿，检查素材引用、画面、字幕、配音和音乐，再保存并重开确认。草稿文字采用整句显示；逐字效果、复杂转场和高级动画在剪映中继续调整。

## 日语口播与双语原稿

在「已有剪映草稿修改」载入草稿并选择字幕轨道，展开「日语口播 → 中文字幕与人物表情」。

1. 点击「读取草稿人物与配音」，选择已在剪映中调整好位置、大小的静态人物示例。程序读取同目录、同文件名前缀的表情图片；勾选本期可用表情。
2. 导入日语 TTS 原稿及中文对照稿。两份稿子的句数可以不同，中文使用作者提供的内容，模型只建议完整短语的对应与表情，不执行文件操作。
3. 如需改善口播节奏，先展开「整理口播停顿」。默认检测超过 0.9 秒的低音量静音，缩短后保留 0.45 秒；短停顿和音频首尾保留，超过 2 秒的停顿默认不选。逐项试听后生成独立配音。有声音的吸气、叹气和背景音乐不会被当作静音自动删除。
4. 点击「识别日语并对齐双语稿」。本地 ASR 使用日语转写与词级时间；清理停顿后会识别新配音。检查每段日语、中文、起止时间和表情，低匹配段必须确认。
5. 输出副本。人物格式沿用所选示例，连续覆盖配音时长，相同表情合并。中文字幕沿用所选字幕轨道的样式，按完整短语断句，定位到对应日语的词级时间，不按字数平均分配时间；每条字幕末尾标点自动清理，仍需播放核对。

本地识别依赖助手配置中的 faster-whisper 模型与外部 Python。停顿处理依赖 FFmpeg，不依赖识别语言。当前停顿处理支持原速、30 分钟以内的单段配音；自动合并至草稿时，超出新配音时长的其他动态轨道会阻止输出，避免失去同步。多角色可逐条人物轨道处理；混合音频不会自动判断说话人。

输出区可以选择剪映草稿根目录。新建模式直接保存新草稿并分配独立标识；干净覆盖模式完整替换本次载入的原草稿目录，备份保存在工坊数据目录的 DraftPublishing/backups 中。覆盖前须在剪映保存并关闭该草稿，原文件发生变化或被占用时会阻止覆盖。覆盖失败会恢复原目录。保存后返回剪映首页查看草稿，并验收播放与保存。
