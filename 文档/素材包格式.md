# 立绘素材包规范 v1

## 目录结构

```text
sprite-packs/
  <pack-id>/
    pack.json
    games/
      <作品目录>/
        <原始角色与图层文件>
工作数据/
  exports/
```

`pack-id` 必须稳定，建议使用 `a-z`、`0-9`、`-` 和 `_`。作品与角色显示名可以使用 Unicode。

## pack.json

```json
{
  "formatVersion": 1,
  "id": "my-pack",
  "name": "我的立绘素材包",
  "version": "1.0.0",
  "games": [
    {"folder": "作品名", "adapter": "krkr-txt-v1"}
  ]
}
```

v1 支持的适配器：

- `krkr-txt-v1`：TXT 坐标、PNG 图层、可选 `_info.txt/.sinfo`。
- `krkr-pbd-v1`：PBD、SINFO 和 PNG 图层。
- `png-position-v1`：坐标写在 PNG 元数据中。

`pack.json` 用于标识、版本管理和将来的校验。当前程序也会对 `games` 下的已知结构自动检测。

按作品单独压缩时，建议每个 ZIP 使用 `games/作品名/原始角色与图层文件`，可在外面再套一层包名目录。解压导入会保留 `games` 和作品名；目录导入也兼容直接选择 `games`。导入后重启或重新扫描，使姿势和表情进入选择清单。

## 导入新作品

1. 保留解包后的原始文件名与目录层级。
2. 在某个素材包的 `games` 下新建作品目录。
3. 将作品加入 `pack.json` 的 `games` 列表并选择适配器。
4. 重启合成器。
5. 检查作品、角色、服装和表情数量，再进行实际合成。

## 安全规则

- 程序不得修改或覆盖 `sprite-packs` 里的任何文件。
- 所有导出只能写入 `工作数据/exports` 或用户显式选择的目录。
- 本地素材包不进入 Git，只能提交自制或明确获得再分发授权的测试素材。
- 新格式无法识别时应报错或生成诊断，不应覆盖原文件进行“修复”。
