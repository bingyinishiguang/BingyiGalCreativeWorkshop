# 素材、配音与人物工作流

入口：工具箱 → 已有剪映草稿修改 →「素材、配音与人物」。更新代码后重启工坊；原草稿、原音频不会覆盖。

## 素材路径修复

载入草稿，展开素材修复，输入素材库目录，默认 `F:\Assets`。扫描材料表的 `path` 字段，按原文件名查找候选。一个同名候选也需要手动选择；多个候选如果在预算内校验哈希一致，显示「内容一致」，否则显示多候选。候选列出完整路径及文件大小。

旧路径无权访问单独标注，不能据此断言素材已经删除。未匹配项暂不修复。选定后输出独立副本，仅修改这些材料的 `path`；不调整时间轴，不合并当前页面尚未输出的字幕编辑。修复后需要继续校对或安排人物时，先载入修复副本。

单次素材扫描最多十万文件，不跟随链接目录；候选内容校验最多使用 100 MB 读取预算，超过预算保留歧义。原始缺失文件无法读取时不能核对其旧内容，因此单一同名匹配也不是自动认定正确。输出前再检查候选存在、大小及已经计算的哈希。

## 日语配音重复检查

使用实际日语 TTS 原稿和日语识别结果。例：三分钟音频在第 88 秒说了一句「一緒に遊びませんか」，第 90 秒又完整说一次，但原稿只出现一次。重复可以横跨两条字幕，也可以在一条字幕里。

1. 导入配音，或刷新音频库并选择配音
2. 粘贴或上传日语原稿
3. 使用助手设置中的本地 faster-whisper 模型重新识别，语言固定日语，保留词级时间；已有日语 SRT 可上传并关闭重新识别
4. 检查疑似重复的第二次朗读，试听前后音频，调整删除起止秒数
5. 勾选「已试听确认」，输出清理配音

识别仅在明确点击检查且启用重新识别时运行，不调用翻译或聊天 API。标记基于相邻、规范化后精确重复的 3–80 字短句，原稿出现多次的句子不自动标记。识别结果存在漏字、错字、插话或相隔较久时可能漏报；它不是全面的 TTS 质量判断。

所有切口都是识别估计，包括词内部按字符估计的边界，不能当成精确强制对齐。只有句级 SRT 时估计更粗，需要仔细试听。允许在候选区间附近一秒内调整；重叠、越界、无效或重复的删除区间被拒绝。默认没有勾选删除。

原配音保持不变，清理版为独立 PCM WAV，自动加入音频库，保留删减记录。PCM16/32 切口两侧有至多 5 毫秒的独立淡入淡出，不交叉混合不同音节，不额外缩短时长。PCM8/24 保留原采样格式但不做淡化。支持 30 分钟、解码后 256 MB 以内；其他音频格式需要本机 FFmpeg，否则先转 PCM WAV。损坏或非 PCM WAV 会给出提示。

下一步必须使用清理版重新识别、翻译并生成字幕，再安排人物。此工具不会移动已有剪映项目的多轨时间轴，也不会直接复用旧字幕的时间戳。

## 人物表情安排

第一版以已有草稿为入口。先在剪映导入多张表情立绘，并放好一个静态示例片段，调整人物位置、大小，拉到希望覆盖的口播范围。

载入草稿，选择已校对的字幕轨道，点击「读取立绘与轨道」。选择人物轨道及示例片段；勾选实际人物素材，填写默认、微笑、无奈等表情标签。背景图也会出现在静态图列表中，不要把背景勾作人物。

填写角色性格和切换要求，使用当前聊天模型生成建议。发给模型的上下文只包含字幕索引与文字、原稿、素材 ID、表情标签和要求，不包含文件路径或密钥。模型返回递增的字幕索引，不拥有修改时间或文件的权限。切换从第一条字幕开始，实际秒数由程序依据字幕计算。

建议显示对应字幕序号、选择的表情和理由。可以手动改选表情并撤销上次选择。生成建议不会写草稿，输出独立人物副本才生效。字幕、示例片段或轨道改变后需重新生成。

仅替换所选示例片段的覆盖区间；区间外其他片段、其他轨道、材料表保持原样。位置和大小沿用示例，不会根据不同图片自动校准人物中心。无关键帧、无反放、速度为 1 的静态 PNG/JPG/WEBP 示例受支持；视频立绘、复杂动画和逐表情位置校准以后再扩展。立绘文件缺失时先修复路径。

计划、表情标签及撤销暂属于当前页面，关闭后不会恢复；已输出副本可继续在剪映编辑。字幕文字和样式的持久进度仍沿用原工作台。每项工具独立输出，不会隐式合并其他未输出改动。建议依次「路径修复副本 → 载入 → 字幕修改副本 → 载入 → 人物安排副本」。

## 日语原稿与中文对照字幕

已有草稿工作台提供「日语口播一键生成剪映草稿」。载入已有草稿，准备日语原稿与中文对照稿，然后点击「一键处理并保存剪映草稿」。默认自动识别草稿中的透明人物示例与配音，保守缩短长停顿，安排中文字幕与人物表情。无需逐条确认字幕，最后在剪映完成微调。

处理完成后弹出保存选择，默认「干净覆盖当前草稿」，也可以另存到自己选择的目录。处理阶段不写入原草稿；覆盖时先建立原目录外的备份，再完整替换目录。草稿被剪映占用或保存失败时保留已经处理好的结果，可修正后重新保存，无需重新识别。

人物轨道或配音有多个候选时，在「高级选项与可选核对」中选择一次；程序不猜测讲话者。已有配音名称含明确的口播或自然停顿标记时可自动选取，避免选到 BGM。高级选项也可关闭停顿整理、手动调整表情或逐条核对。

一键输出默认将人物 X 坐标设为 0，保留格式示例的缩放、Y 坐标与旋转。需要人物位于画面左右两侧时，可关闭「人物水平居中」。

表情文件无需采用固定命名格式。「选择表情图片，无需重命名」可选择任意文件名的静态图片，再填写供模型理解的显示标签，例如「微笑·站姿」「认真·坐姿」；标签保存在本机，不修改图片文件名。模型依赖标签提供建议，不会从任意编号文件名自动推断表情。

不同姿势可以选择人物轨道上各自已经调好的格式示例，分别沿用缩放、Y 坐标、旋转与裁切等设置。未指定时尝试沿用草稿中同一图片的示例，否则沿用主要人物示例。PNG 的透明留白、人物大小及姿势差异需要用相应格式示例处理，不要求重新命名，也不把所有姿势强行视为同一格式。

运行时显示当前步骤、已用时间以及识别、翻译和字幕安排的状态。后台模型请求可能需要较长时间，不使用无法保证准确的倒计时。停止操作会在当前后台操作结束后停止，保存阶段采用完整发布操作。

百度翻译辅助可选，默认关闭。不开启时使用本地日语识别与中日原稿匹配，不发送百度请求。需要辅助时勾选「使用百度翻译辅助匹配」，并在助手设置配置百度 APP ID 与密钥；开启后只向百度发送日语完整句子与短语，不上传音频或素材路径。

模型先参考完整句子的百度译文匹配作者中文，再结合句子上下文和短语译文细分字幕。中日语序不同时按实际日语朗读顺序显示对应中文，不按字符数量平分时间。核对列表显示日语、百度参考译文与可编辑的作者中文；最终字幕使用作者中文，参考译文不会直接覆盖它。

参考译文缓存在本机工作数据中，重复任务复用缓存。首次运行逐条翻译会增加等待时间，界面显示当前进度。翻译失败或配置缺失时明确停止，已成功的缓存保留，修复后可重试。参考译文可能有错误，不能作为语义正确的保证。

本地识别固定使用日语转写及词级时间。字幕起止取对应日语词的时间边界，句末逗号、句号等标点清理，短语保持完整。译文跨多个日语分句时合并必要区间。自动结果可直接输出，识别匹配率不代表翻译语义准确率；需要精细校对时使用高级核对列表，或在剪映调整。

如需缩短长停顿，先使用「自然停顿清理」，保留句间呼吸，再对清理配音重新识别。人物位置、缩放及旋转沿用草稿示例，表情覆盖所选配音范围。原始配音不修改。

## 直接保存到剪映

「保存到剪映」可选择草稿根目录，默认使用本次载入草稿所在目录。新建模式直接创建可继续编辑的草稿；同名时添加编号，保留原稿。

「干净覆盖当前草稿」只替换本次载入的草稿目录。先在剪映保存并关闭该草稿。程序在原目录外建立并校验 ZIP 备份，准备完整输出后替换目录，移除旧自动保存副本；替换失败时恢复原目录。

普通校对保存会检查载入后原稿是否变化。一键结果完成后明确选择覆盖时，备份点击保存当时的草稿版本；选择另存则保留原稿中的新修改。发布期间草稿再次变化或文件被占用时停止保存，处理结果保留以供重试。输出完成后查看结果路径及备份位置。
