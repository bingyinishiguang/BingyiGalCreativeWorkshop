# Galgame剧情生成器

入口：工具箱 → Galgame剧情生成器。

这个模块把已经写好的剧情制作成可继续编辑的剪映草稿，MP4 用于辅助预览。内置冰翼自己的六种表情、工作室与窗边背景，以及对白、旁白和无字过场素材。聊天模型沿用 AI 字幕助手里的配置。

## 从剧本到视频

1. 点击「导入剧情」，粘贴文字或选择 TXT / DOCX。常用写法是 `冰翼：台词`、`【冰翼】台词`、`旁白：描述`。没有角色标记的段落按旁白保留。`心声：描述` 和 `冰翼（心声）：描述` 导入为心理活动。原文可以在「角色与声音 → 导入原文」查看。
2. 在左侧选择片段。中间可以修改类型、说话角色、正文、背景、音频、时长，以及人物的位置和表情。片段可以增加、删除和排序；编辑和 AI 修改支持撤销、重做。
3. 在「角色与声音」中绑定人物可用的立绘和音色。新增人物可以填写人设，导入透明 PNG / WEBP。背景也可以从现有背景库选择或导入图片。
4. 选择配音和 BGM，播放预览，检查文字和切句时机。
5. 保存项目，再点击「生成剪映草稿」，在剪映中继续精剪。需要视频预览时点击「预览 MP4」。

## 配音

每句可以使用软件生成的配音，也可以导入已经准备好的 WAV、MP3 等音频。导入音频后会绑定到当前句；软件配音保留独立版本，不覆盖原音频。

角色对白默认播放配音，旁白和心理活动默认静音，即使旧项目绑定了音频也不会自动播放。勾选「本句播放配音」可启用；主动导入音频或生成本句配音会开启。批量配音只处理启用配音的句子。角色可以分别选择音色，旁白音色也能单独设置。没有选择时使用配音页面当前的声音预设。剧情模块的中文台词使用中文推理语言，不改动全局预设。已有配音的句子不会被「生成尚未配音的台词」重复生成；选中某句后可以重做。

本地配音组件可选。没有模型、运行环境或合适的硬件时，可以一直使用导入音频完成视频。单次软件配音沿用现有 TTS 的 1000 字限制，长段落请拆成多句。

修改已经配音的台词后，会提示台词与配音原文不一致。重新生成配音，或手动绑定匹配的音频。批量配音期间如果台词被修改，完成的旧版本仍保留在音频库，不自动替换新台词。

## 显示与节奏

默认整句显示。有配音时，片段长度覆盖音频和句尾停顿；默认停顿 0.15 秒，可以设置为 0。预览以实际音频播放进度推进，导出以整数视频帧对齐音轨。

逐字显示是单句可选效果，同时等待文字和音频完成。没有配音时使用可编辑的片段时长。旁白与心声默认使用统一的 2 秒，可在设置中修改；单独修改片段时长会取消沿用统一时长。「所有旁白沿用统一时长并关闭配音」可应用到旧项目。对白按实际字形宽度排版，每页两行；长对白自动分页，音频连续播放，不通过无限缩小字号塞入文字。分页过快会提示检查。

背景和人物按比例显示。单人默认居中近景，双人左右站位，三人左中右，四至六人进一步缩小；可点击「自动站位」「居中近景」「全身构图」。单击画布人物选中，拖动移动，拖右下角手柄缩放。人物使用原图画布定位，换表情保留位置；不同来源的立绘仍需统一原图尺寸和头部位置。点击「沿用到后续同场景」复制站位和层级，保留后续已有表情，遇到背景变化或无字过场停止。

图层由下到上：背景、按 z 排列的人物、渐变底板、说话者头像、常驻字标、姓名正文、语音进度条和循环冰晶提示。人物面板可前移或后移图层。选中框和缩放手柄只用于编辑，不进入 MP4。

双击画布正文直接编辑，Ctrl + Enter 或离开输入框保存，Escape 取消。文字位置和字号可在面板调整。四种皮肤为冰蓝、紫色、暖棕、灰蓝；片段可覆盖项目皮肤。头像裁切按角色保存源图比例，随表情同步。文字使用白字深色描边。

连续切句默认直接替换文字，不加黑场。只有主动勾选「本句开头淡入」才使用设置的淡入时长。循环提示和语音进度条均按视频时间绘制，进入实际 MP4。

BGM 由创作者选择，展开「配音与 BGM」后，可以设置音量、配音期间的音乐比例、开头和结尾淡入淡出。短 BGM 自动循环。无字过场只显示选择的图片。

## 和冰翼聊天

可以聊灵感、生活琐事，也可以要求检查错别字、排版或安排表情与背景。快捷按钮把指令填入聊天框，点击发送或按 Ctrl + Enter 提交。

剧本操作先展示可选择的建议，再点击「应用建议」。普通闲聊不会自动进入剧本。AI 只能引用存在的片段和素材，表情只能从绑定到相应角色的立绘中选择。手工修改剧情后，旧建议失效，避免覆盖新内容。

聊天人设和角色人设分别保存。模型配置共用已有配置窗口；密钥不进入剧情项目、导出文件或模型的剧情上下文。

## 保存与输出

输入文字时即时写入浏览器暂存，停顿约 1.5 秒后自动保存本地项目；仍建议在重要改动后点击「保存项目」。没有浏览器暂存时会打开最近保存的项目。已完成的导出记录可以在重新打开项目后恢复。

项目保存在 `工作数据/GalStory/projects`；新导入的图片保存在 `工作数据/GalStory/assets`；MP4、项目快照和编码日志保存在 `工作数据/GalStory/exports`。素材库音频和图片仍使用现有稳定编号。复制项目到另一台电脑时，需要同时带上引用的素材库和自定义图片。

MP4 预览固定输出 1920×1080、30fps、H.264 / AAC 的 MP4。编辑器按钮和聊天窗口不进入视频。导出是后台任务，有进度、取消和结果校验。取消配音时，当前推理请求完成后停止下一句；已完成的音频保留。任务失败不会把未完成视频展示为成品。

导出需要 FFmpeg。本机已经检测并验证；其他电脑需安装 FFmpeg 并加入 PATH 后重启工坊。当前使用 Windows 自带宋体和微软雅黑完成中文测量与绘制，预览和导出共用同一渲染器。

首版的人物与背景切换发生在片段边界，尚未提供一句台词内部的动作关键帧、互动游戏分支或游戏发布功能。作者可以把同一段演出拆成多个片段继续调整。
