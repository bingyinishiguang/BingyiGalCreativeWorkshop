# AI 字幕剪辑助手（第一版）

在「工具箱 → 剪映草稿自动生成」顶部点击「AI 剪辑助手」，或点击右下角可拖动的悬浮球。

## 第一次使用

点击助手的「配置」，分别设置三个服务。聊天模型和百度翻译的密钥由本地后端保存在工作数据的 `SubtitleAssistant/settings.json`；查询配置不会返回密钥，导出草稿也不携带密钥。该本地文件不是加密保险库，请勿分享它。密码输入留空保留已保存的密钥；删除模型配置可以移除其密钥。

### 本地语音识别

填写已安装 faster-whisper 的 Python 路径，以及本地模型目录（含 `model.bin`、配置与分词器文件）。不自动下载模型。

其他设备可选 CPU + int8。源码运行时 Python 路径留空使用工坊的解释器；该解释器也必须安装 faster-whisper。打包版本必须指定外部 Python 环境。识别在独立进程执行，取消会结束识别进程。

### 百度翻译

填写百度通用文本翻译的 APP ID 和密钥。语音识别与文本翻译是独立服务。暂不需要翻译时，取消勾选「识别后翻译字幕」。识别日语请选日语，译文选中文。

### 自定义聊天模型

填写配置名称、API 地址、模型 ID 和 API Key。接口须兼容 Chat Completions，地址通常以 `/v1` 结尾，也接受完整 `/chat/completions` 地址。远程地址使用 HTTPS，本机环回地址可用 HTTP。

点击「保存并测试模型」检测连接及工具调用能力。支持配置多个模型，在聊天框底部切换。模型接口不同或不支持工具调用时会显示实际错误；按钮流程不依赖聊天模型。

## 字幕流程

1. 导入配音，或选择项目里的配音片段。
2. 选择原语言、译文语言和是否翻译。
3. 点击「识别并生成字幕」，查看进度；任务可以取消。
4. 完成后点击「写入当前项目」，在时间轴预览字幕。
5. 点击「生成剪映草稿」，输出独立草稿文件夹。

没有背景时会补充覆盖配音的纯黑镜头。已有项目的背景、人物和独立文字沿用原项目。识别字幕使用源音频时间，写回时沿用音频裁切与时间轴偏移映射。

任务期间可以继续编辑。任务结果保留启动时的项目快照；若项目已变化，助手拒绝覆盖当前版本。可以撤销期间修改后写入，或丢弃结果并重新运行。后台任务不直接覆盖已保存项目。

## 聊天示例

- 「识别这段日语配音，翻译成中文字幕。」
- 「把第三条字幕改成：今天想和大家说几句话。」
- 「字幕改成白字黑边，字号设为 10。」
- 「去掉这段配音的字幕标点。」
- 「撤销刚才的修改。」
- 「输出剪映草稿。」

模型仅能调用应用允许的字幕工具，参数和整个项目都会经过校验。字幕改字和样式修改接入时间轴撤销；撤销或导出请单独发送。暂不支持自动选背景、切换人物和调节音乐节奏。

## 作者原稿与标点规则

展开助手内的「作者原稿对照与字幕规范」，上传 TXT（支持 UTF-8、UTF-16、GB18030）或粘贴原稿。对照在本地执行，不调用聊天模型或翻译服务。

默认保守匹配：显示当前字幕、原稿和可编辑结果，只应用已勾选条目；重复句、跨语言或断句差异较大的内容需要人工核对。确定每行对应一条字幕时，可切换逐行方式，行数须与字幕数量一致。

点击「应用勾选项并保存原稿记录」后，原稿文本与文件名随配音片段进入项目，保存项目后重新打开仍保留；修改可以撤销，时间戳不变。仅上传或粘贴而未应用的原稿尚未进入项目。

配音字幕在校验、保存、翻译写入、聊天改字和导出时统一规范：句间使用中文逗号，每条字幕末尾去掉逗号、句号等句末标点，保留必要的引号、括号与小数。作者原稿文本保留原样，独立标题不受此规则影响。

## 已有剪映草稿修改

工具箱新增独立入口「已有剪映草稿修改」。选择工程目录或其中的 `draft_content.json`，载入后明确选择中文字幕轨道。可直接改字、对照原稿、预览标点规范和撤销本页编辑，再点击「输出修改副本」。

加密格式目前实际验证了本机剪映 `7.2.2.53989`。适配设置中填写包含 `videoeditor.dll` 的版本目录；源码版可使用当前 Python，打包版使用工坊内置适配器，外部 Python 可选。编解码在独立进程执行，版本不兼容会报错，不退回覆盖原工程。

副本保存在工作数据的 `ExistingDraftEdits/copies`，包含原工程资源、修改后字幕 SRT 和修改记录。其他轨道、素材引用与时间轴保持不变。保存前后检查原文件哈希，并验证加密往返一致性；剪映在期间保存了原工程时，会拒绝输出并要求重新载入。

本版不注册到剪映草稿列表、不直接写回原工程。原素材路径继续沿用，因此不会自动修复「媒体丢失」。单次校对或修改支持 1000 条以内，完整草稿资源副本限 512 MB。不同草稿及版本需要检查最终播放与保存重开效果。

### 字幕工作台

原字幕与修改结果并排显示，顶部操作栏集中提供撤销、重做、标点规范、保存进度和输出副本。搜索同时查找原文与结果；「只看改动」按原草稿文字计算。批量替换是精确文字替换，作用于整个选中轨道，筛选隐藏的字幕也包含在内；先显示对照，勾选后应用。

定位栏输入字幕序号（如 `28`）或时间（如 `1:20`、`0:2.05`），点击「定位」或按 Enter，会清空筛选并定位对应字幕。上一条、下一条在当前筛选结果中移动。时间落在字幕间隙时定位下一条，不改变时间轴。

「字幕检查」在本地提示空字幕、超过 32 字、每秒超过 12 字和时间重叠，可以筛选或点击提示定位。长度和阅读速度只是人工核对提示，不自动改写或调整时间；空字幕需要补全后才能保存进度或输出副本。

右侧 AI 助手沿用本地已有模型配置，可打开「模型配置」设置。允许逐条改字、批量替换、规范标点、原稿对照与当前轨道样式工具，不允许模型改变时间戳、其他轨道或文件路径。聊天回复展示待应用建议，勾选应用后可撤销；手动改字、切换轨道或修改原稿会让旧建议失效。原稿对照中的重复句或低可信匹配仍留给作者人工核对。

切换轨道保留本页其他轨道的编辑与各自的撤销、重做记录，每轨道最多保留 30 步。撤销后新编辑会丢弃对应的重做分支；上传或直接编辑原稿也可撤销。点击「保存编辑进度」将各轨道文字、原稿、对照方式、最近聊天和修改记录保存在 `ExistingDraftEdits/progress`，重新载入同一原草稿自动恢复。输出修改副本后也会保存进度；输出结果列出具体改动。撤销栈和未应用的预览建议仅在当前页面保留，重新载入草稿会清空撤销记录。

进度依据原草稿内容哈希恢复；原草稿变化时不会套用旧校对结果。其他窗口已经保存更新进度时，旧窗口会提示冲突。文件夹改名后的进度查找及丢失素材路径修复暂未处理。

### 字幕样式与栏目预设

右侧展开「字幕样式与栏目预设」，勾选要调整的属性，再点「预览样式调整」。支持字号、字色、描边颜色、描边宽度、横向与纵向位置，以及复用草稿中已有的可用字体。字号使用剪映单位 2–50，描边宽度为 0–0.3（常用 0.08），坐标为 -1–1，Y 越大位置越高。未勾选属性恢复为原草稿对应属性；套用栏目预设则只覆盖预设中包含的属性。

建议卡片位于侧栏顶部，列出逐条样式差异。勾选「样式」后应用于当前轨道的全部字幕；可以撤销，也可以预览恢复原样式。侧栏的颜色和位置示意不代表剪映实际渲染，字体、字号与描边效果应在剪映中验收。带关键帧的字幕暂不允许统一移动位置，渐变填充或多层描边暂不允许统一调整对应属性，其他原有效果保留。

已应用的样式可命名保存为栏目预设，记录位于 `ExistingDraftEdits/style-presets.json`，重启后仍可复用。字体来自原草稿已有字体描述，预设不会复制字体文件；字体路径失效时，套用或输出会提示重新选择，仍可恢复原样式。预设名称不能重复，最多 100 个。跨草稿使用时不会改变素材路径。

聊天也支持「把字幕字号统一改成 6，颜色保持原样」或「套用已保存的字幕预设」。模型只使用受限样式工具和本地预设 ID，不能提交任意字体路径。混合改字与样式建议可以分别勾选；所有样式改动仍以预览后应用为准。

### 自动保存与冲突恢复

「自动保存进度」默认开启，输入字幕时立即记录本页编辑，停顿约 5 秒后保存本地进度，不移动输入焦点。可以关闭此选项，改用手动保存。重新载入草稿或点击「返回工具箱」前，会先保存当前进度；输出副本后也保存。作者原稿保持原文，字幕标点只在规范或输出等相应操作时处理。

如果有空字幕、原草稿已变化、字体失效或其他窗口已保存更新版本，自动保存暂停，保留本页编辑并显示原因。修正后点击「保存编辑进度」可恢复。也可以点击「备份本页编辑并重新载入」，先将文字、样式、原稿和记录写入独立的 `ExistingDraftEdits/recovery-backups` JSON，再载入最新进度。备份不会自动覆盖当前共享进度。

展开「编辑备份与恢复」可随时备份本页全部已编辑轨道。刷新后选择备份，再「预览恢复」查看文字与样式变化。点击「恢复当前轨道」才会将该轨道的文字、样式、原稿、对照方式和记录恢复到本页，其他轨道保留当前编辑；恢复可撤销、重做，保存进度或自动保存后才更新持久进度。

备份根据原草稿路径、内容哈希、轨道编号和字幕数量核对，原草稿已变化的备份不能自动恢复。会话过期时新备份仍保留原草稿标识，重新载入后可核对恢复；此前无原草稿标识的旧备份只可保留 JSON 人工核对。含空字幕的备份允许预览和恢复，但需补全后再保存或输出；缺失字体需要人工重新选择。列表从最近 100 份文件中查找当前轨道，最多展示 50 份，不删除旧备份。

损坏的旧进度不会阻止载入原草稿，也不会被静默套用；下次保存前会保留 `.damaged-…json` 原文件备份。撤销栈、尚未应用的模型建议和未应用的样式表单仅属于当前页面；关闭页面前，仍未保存的编辑会触发浏览器离开提示。

## 素材、配音与人物

已有草稿工作台新增素材路径修复、日语重复配音试听删减及人物表情安排。详细操作、工具独立输出顺序、音频格式要求及第一版限制见 [素材配音与人物工作流](素材配音与人物工作流.md)。清理后的配音需要重新识别字幕，再安排人物；不会直接移动已有项目的多条轨道。
